CityLab Energy Control

Monitoramento e controle de consumo energético em instituições públicas para Cidades Inteligentes

Sobre o projeto

O CityLab Energy Control é um projeto desenvolvido no CityLab da Fatec Rio Preto com o objetivo de utilizar tecnologias de Internet das Coisas (IoT) para auxiliar no monitoramento do consumo e das condições da energia elétrica em instituições públicas.

A proposta busca possibilitar o acompanhamento contínuo de informações relacionadas ao sistema elétrico, permitindo uma visão mais clara do comportamento do consumo energético e contribuindo para uma gestão mais eficiente dos recursos.

Como funciona

O protótipo utiliza um microcontrolador ESP32 conectado a sensores responsáveis pela obtenção de informações elétricas do circuito monitorado.

Os dados coletados podem ser disponibilizados por meio de uma conexão Wi-Fi e enviados para uma plataforma de Internet das Coisas, possibilitando seu acompanhamento e organização.

A arquitetura foi desenvolvida pensando na possibilidade de expansão do sistema para diferentes circuitos e instalações elétricas.

Situação atual do protótipo

Atualmente, o protótipo encontra-se em fase de desenvolvimento e realiza o monitoramento de apenas um dos circuitos presentes no quadro elétrico.

Neste momento, o circuito utilizado para os testes é o circuito de iluminação. Essa abordagem permite validar o funcionamento do sistema antes de sua expansão para uma instalação elétrica completa.

Perspectivas futuras

Uma das principais perspectivas para a evolução do projeto é ampliar a capacidade de monitoramento do protótipo para que ele possa acompanhar os diferentes circuitos de um quadro elétrico de forma integrada.

Dessa forma, o sistema poderá fornecer uma visão mais abrangente do comportamento energético da instalação, contribuindo para a identificação de padrões de consumo, possíveis anomalias e oportunidades de melhoria na utilização da energia elétrica.

Tecnologias utilizadas

ESP32

Microcontrolador responsável pelo processamento das informações e pela comunicação do sistema.

PZEM-004T V3

Sensor utilizado para a obtenção de informações relacionadas às grandezas elétricas.

Wi-Fi

Utilizado para a comunicação entre o dispositivo, a rede local e os serviços de IoT.

Arduino IoT Cloud

Plataforma utilizada para integração e gerenciamento dos dados do dispositivo IoT.
